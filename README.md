# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python menu-driven program containing three useful tools. The tools are a Simple Calculator, a To-Do List, and a Number Checker. The program uses variables, input/output, conditionals, loops, lists, functions, and f-strings. The main menu continues running until the user chooses the Quit option.

## Tools

### 1. Simple Calculator

The calculator performs addition, subtraction, multiplication, and division using two numbers entered by the user.

### 2. To-Do List

The To-Do List allows the user to add tasks, view tasks, and remove tasks. The tasks are stored in a list that changes while the program is running.

### 3. Number Checker

The Number Checker determines whether a number entered by the user is positive, negative, or zero.

## How to Run

1. Open the project folder in VS Code.
2. Open the VS Code terminal.
3. Make sure Python is installed.
4. Run the program with:

```text
python toolkit.py
```

5. Choose a number from the main menu and follow the instructions.

## Features

* Menu-driven program
* Three different tools
* While loops
* If / elif / else conditionals
* Lists
* Functions
* User input
* F-strings
* Friendly error messages
* Graceful handling of invalid choices

## Reflection

The hardest part of this project was connecting all the tools to one main menu. I had to make sure that the menu continued to appear after each tool finished. The To-Do List was also challenging because the list had to change when tasks were added or removed. One useful part of testing was checking invalid choices and making sure the program did not crash. I also tested division by zero and invalid number input. With one more week, I would add a countdown timer and a random number guessing game. I would also improve the design of the menu and add more useful tools.
