PERSONAL MINI-TOOLKIT PLAN

1. TOOLS

Tool 1: Simple Calculator
This tool asks the user for two numbers and an operation, then calculates the answer.

Tool 2: To-Do List
This tool allows the user to add tasks, view tasks, and remove tasks from a changing list.

Tool 3: Number Checker
This tool asks the user for a number and tells them whether it is positive, negative, or zero.
